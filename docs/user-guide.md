# MarketAI 新版操作教程

完整图文版（34 个操作步骤、72 张逐步截图）见 [HTML 使用教学](tutorials/marketai-tutorial.html)，支持下载后离线打开、目录跳转和截图放大；本页保留文字速查。[下载与打开说明](tutorials/README.md)。

适用版本：2026-10-23 已上线的营销测试与素材编辑流程（main `8cf5ba8a`）。图文版逐图保留 10-18 基础示例与 10-23 编辑练习的拍摄日期。默认从 **Marketing Tests** 开始，首次完成“提供资料、确认理解、确认方案”，后续在同一页生成、检查、修订、导出和分析结果。界面部分按钮为英文，下面保留对应名称方便寻找。

[打开 MarketAI](https://marketai-web-production.up.railway.app) · [项目首页](../README.md) · [文档目录](README.md)

## 1. 登录并配置 Key

接受邀请后登录并完成 MFA，选择持有产品资料的 Workspace。当前为邀请制 Beta；没有工作区时，由运营人员发出邀请。工作区切换后，产品、Key、预算和测试记录分别隔离。

第一次体验可以明确选择 **Controlled Mock**：不调用付费供应商，模拟记录不用于证明真实效果。已有真实测试不要混入模拟素材或数据。

需要真实 AI 时，由 **Owner** 打开 **Settings → Provider credentials**：

1. 在 OpenAI、Google Gemini 或 Seedream（Volcengine Ark）区域点 **Add … key**，输入对应供应商的 API Key，可填写用途标签。
2. 点 **Save and use for generation**。登录之后不会再要求输入验证码（MFA 只在登录时验证）。
3. 确认显示 **Key enabled for generation**。若显示 **Saved, not in use**，点 **Use for generation**；若请求结果不明，先 **Reload status**，确认已存状态后再操作。
4. 换 Key 用 **Replace key**，停用用 **Remove**。保存后页面不再回显原 Key，不需要把 Key 发到聊天或代码仓库。

保存只确认加密存储及绑定，不验证供应商账户、模型权限或余额。Owner 还需设置 USD Spend Guardrail；如果提示权益、模型报价或策划/QC 配置缺失，由运营/部署维护人员处理。Member 可在已有授权和预算内使用。

图片供应商可以与策划、视觉 QC 的供应商不同；保存 Seedream Key 不表示已配置文本策划或视觉检查模型。真实调用前以页面就绪状态、模型和费用为准。

## 2. 提供产品资料，确认 AI 理解

进入 **Marketing Tests**，点 **New test**。粘贴产品介绍、目标客户、使用情境、顾虑和有出处的购买理由；也可选择已有产品，再点 **Save product and start**。可按下面结构整理已有资料，无需全部填完才开始：

```text
产品是什么、适用的具体型号/变体：
客户为什么需要这类产品：
为什么考虑我们，而不是其他选择：
主要客群与使用情境：
认证、性能、价格等声明的原文与来源：
不适用的条件或用户顾虑：
```

查看 **Draft product understanding** 旁的模型及费用上限，确认后让 AI 起草。检查“为什么需要这类产品”和“为什么考虑我们这款”是否分开。核对事实及引用，修正不准的内容；AI 推测可以改，但认可推测不等于验证有效。未知项继续保留。

点 **Confirm understanding and continue**。之后补充资料会创建新修订，需要重新理解、确认；历史素材和快照保留。

## 3. 确认测试方案

让 AI 起草方案，直接修改角度和各自的表达。比如“安心使用”是角度，“认证解读”是表达，认证编号是支持事实。不同角度可有不同数量、不同类型的表达；需要专门比较时才展开对照视图，不必凑满矩阵。

确认前重点看：

| 要确认的内容                     | 如何判断                                                     |
| -------------------------------- | ------------------------------------------------------------ |
| 本小轮问题和比较对象             | 这次比较哪些方案，或复测哪个具体素材？                       |
| 主动变化、允许配套变化、保持条件 | 整套组合都变时，只能解释组合表现；判断单因素需对应的受控版本 |
| 业务目标与判断规则               | 达到什么 CPA/ROAS 等目标才值得继续，而非只选排名第一         |
| 预算、周期和停止条件             | 本轮投入多少、何时判断、大轮最多做几轮，何时允许证据不足收尾 |
| 组合与素材覆盖                   | 筛选角度尽量有少量不同表达，预算不足时明确局限               |

点 **Confirm test plan**。默认大轮路线是“筛选角度 → 匹配表达 → 确认组合”；人物、背景等元素只在有明确问题时追加。改方案需要重新确认，旧草稿不能按旧报价继续执行。

## 4. 选择权威实物图并生成

在方案准备素材处选择该准确产品/变体的实拍或权威实物参考图。最多三张，需已发布并有有效使用权；没有可选项时使用 **Upload a product photo here** 进入上传流程，完成门禁及发布后再选择。确认来源、产品身份和使用许可；另一张 AI 广告图不能当作产品外观依据。

参考图支持可见外形、接口等，不证明认证、额定性能或价格。准备草稿后参考版本冻结，生图、QC、反馈修订和导出沿用同一证据；换参考图需修订并确认新方案。

选择供应商、模型、画幅和输出设置，点 **Prepare generation drafts · No charge**。这一步不调用图片模型。打开关联草稿，核对 AI 已带入的主张、表达和文案，预览张数与最大费用，再确认生成。

生成后在同页查看任务。Gemini/Seedream 的 1K/2K 与 OpenAI Standard/High quality 是不同设置，High quality 不表示 2K 输出。缺 Key 或报价的模型不能正式生成，也不会失败后自动换成 Mock。

## 5. 确认本轮规则，AI 批量 QC 与修订

先在 **Confirm this round’s delivery and decision rules** 核对并确认开始日期、周期、Meta 账户时区、真实/模拟模式与判断协议，建立本小轮。真实模式不能补登记过去的开始日期；使用正确的 IANA 时区，例如 `America/Los_Angeles`，不要按浏览器时区猜测。确认后本轮问题和规则冻结，进入素材审核；此时仍可在导出前修订素材。

素材就绪后查看整批 AI QC 的供应商、模型、检查对象及总费用上限，一次确认整批检查。AI 读取实际图片、文案、产品事实、参考图和测试意图，通过项默认收起，优先展示疑点与建议。

人工核对疑点、补充依据及最终质量确认，无需每张图从头填写整份清单。缺少实物参考时外观保留待确认；明显错误不能用整批勾选跳过。修改 AI 判断需要留下理由；认证与量化声明仍需事实支持。

需要改图时，在准确素材版本上选择操作：

| 任务 | 当前入口与要点 |
| --- | --- |
| 按意见修改整张图 | **Modify with AI**：写清调整要求，原图与已有意见进入关联草稿；其他细节也可能变化 |
| 裁剪、旋转 | **Crop and rotate**：在原图拖出矩形，中央手柄移动、四角调整，也可输入百分比；先裁剪后顺时针旋转，不调用图片供应商 |
| 增大尺寸 | **AI enhance and upscale**：选 2×/4×，核对目标宽高与上限；更大不证明恢复了真实细节 |
| 透明背景 | **Remove background**：只选择页面当前支持的模型；核对棋盘格、边缘及 PNG |
| 局部擦除与补景 | **Erase selected area**：矩形或 **Brush**；先调笔刷再涂，**Undo stroke / Redo stroke** 撤销重做，**Clear strokes** 清空；选区外像素和原 Alpha 保留 |
| 从旧版继续 | **Version history and comparison → Continue editing this version**：从选中的旧版分叉，保留原图与旧审核 |

图片工具先点 **Prepare edit draft**（图生图为 **Prepare correction draft**），再在草稿页 **Preview and review cost** 核对动作、来源、模型、数量、尺寸和最高费用，最后 **Confirm and generate**。准备草稿不调用图片供应商；真实模式下生成是新的付费意图。来源、选区、倍数或模型变化后重新准备，结果不确定时先核对任务状态。

新版本都必须重新 AI QC 和人工质量确认，裁剪也不继承原批准。AI QC 不会自动批准。只把本轮实际认可的准确版本用于导出，旧原图、意见及已冻结清单保留。

在版本历史选择 **Source version (left)** 和 **Result version (right)**，拖 **Show source** 比较，用 **Comparison zoom** 在 100%–400% 视图中检查。透明处显示棋盘格；视图缩放不会改变文件像素。冻结或关闭小轮仍可查看、比较，继续编辑使用新小轮并重新审核。

新增图文操作见 [原图编辑与版本比较](tutorials/marketai-tutorial.html#revision)，费用和恢复细节见 [配套参考](tutorials/advanced-reference.html#assets)。

**Approve 只表示这一精确版本质量通过**，不表示投放有效。只把实际认可的版本用于导出；错误初稿保持需修改或拒绝。导出清单冻结后想换图，需另开小轮。

## 6. 导出 Meta 包

完成本轮质量审核与导出条件后创建导出包，等任务就绪再点 **Download Meta package**。包内有图片、`ads.csv`、`manifest.json`、`daily-metrics-template.csv` 和使用说明，保存素材与广告对应所需的固定关系。

如果本次只准备素材，**到下载这里即可停止**。导出不会创建或发布广告。私有链接有时效，过期后回页面重新申请；不要公开分享链接。Safari 可能自动解压 ZIP，可在下载目录查看文件夹。

## 7. 有投放安排后，在 Meta 建广告并对应

需要真实投放时，由用户在 Meta Ads Manager 创建和管理广告。沿用导出文案和命名，回测试页对应实际广告账户、Ad ID 与准确素材，并确认客群、优惠、落地页、版位及偏差。一条素材可对应多个广告；名称只帮助查找，最终以实际 Ad ID 和导出条目对应为准。

同一小轮使用同一账户，不能把同一广告日期重复对应到不同素材。导出或填入 Ad ID 本身不证明已投放，更不证明达标。

## 8. 预检并确认每日 CSV

在 Meta 按冻结的账户时区、USD 币种和 **7 天点击 / 1 天浏览归因**导出，每个广告每天一行，不带 breakdown。优先使用包内空模板的列：

```csv
date,ad_id,spend,impressions,clicks,purchases,purchase_value
```

`clicks` 是 Link clicks。数值不带货币符号或千分位；缺失指标留为未知，不编零。CPA 需 purchases，ROAS 还需 purchase_value。没有投放的广告日也需报表中的明确零行。

选择 UTF-8 CSV（最多 256KB、5,000 行），核对账户、时区、归因和来源，必要时设置列名对应，点 **Preview data and matches**。先处理无法对应、重复、缺日、无效金额及越界等问题；有阻断问题的整批不能确认。

预检通过后点 **Confirm this data import**。同文件重放不会重复计数。更正已有数据时明确选择替代当前有效批次，保持相同广告日集合和口径；旧批次留档。确认后文件输入清空，下次重新选择。

已结束小轮仍可追加真实广告对应、报表、更正和新评估；原收尾及旧判断保留，不重新开放本轮改图或新导出。数据始终标为用户提供，不能冒充 Meta API 独立核验。

## 9. 看结论、请求 AI 解读，再决定下一轮

达到方案约定的投放周期和归因等待期后评估，先看数据充分性、业务达标，再看相对差异与结论范围。默认协议包含最低投放日数、展示/点击/购买/花费要求及结束后的等待期，冻结前可在允许边界内调整；不足时页面说明原因。

可以确认费用后请求 AI 解读。模型解释冻结证据和局限，不改写规则判定，也不自动开启下一轮。审核或数据更正后旧解释成为历史，需要新评估，再决定是否重新付费解读。

两套组合都达标可以都保留；仅相对更好但未达标不能当成功。一张广告有效，只支持这张广告；组合复用还需新增执行版本、另一小轮和新增投放数据。未测搭配保持未知，失败元素不会永久拉黑。

根据下一步建议，让 AI 在候选角度内比较表达，或组织确认轮；确认新方案和费用后才执行。预算或轮次用完可以以“没有达标素材”或“证据不足”收尾，无需强选冠军。

## 10. 有合格证据后，准备本地化或放量

真实业务达标后，可在证据交接区选择精确素材及实际测试的已发布产品/销售方案，确认客群、市场、落地页和适用条件，再准备本地化。只有质量通过、模拟结果或探索性 CTR 的素材没有这项资格。

放量候选还需新执行与另一小轮支持组合复用，再通过市场真值、权利和实际投放对象检查；页面提供准备和只读建议，不启停广告或修改 Meta 预算。本地化版本需重新审核、测试，不继承原素材效果。上游数据更正或质量撤回后，旧交接需要重新核对。

## 遇到问题时

| 页面现象                    | 下一步                                                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Key 已保存但模型不可用      | 核对已启用状态、供应商权限、Workspace 权益、预算及部署报价；保存不保证鉴权成功                                         |
| 后台断连或刷新失败          | 保留当前页面的 CSV、勾选和编辑，恢复后点 Refresh；重新读取成功前业务动作与旧下载链接暂停。整页重载不保证保留未提交文件 |
| AI/图片任务显示 uncertain   | 保留记录并联系维护人员核对供应商回执；不要反复创建新付费意图                                                           |
| AI 输出未通过结构或证据检查 | 查看反馈并修正资料/要求；显式重试已知失败的真实调用仍可能产生新费用                                                    |
| 方案或审核已变化            | 刷新当前版本，重新确认需要的方案、审核或评估，历史结果不能直接沿用                                                     |
| CSV 被阻断                  | 按预检修正对应、金额、日期及口径，再预检；不要删掉问题行后假装整批完整                                                 |
| 下载链接失效                | 回页面重新申请；若审核/权利已撤回，先处理资格                                                                          |

更多细节见[交接与评估说明](product/ai-marketing-delivery-loop.md)、[营销 QC](product/ai-marketing-ai-qc.md)及[开发与运行](development.md)。真实供应商能力与费用以有效 Key、当前模型和当次报价为准。本次新增编辑段仅使用 Mock 验证，未做新的付费模型效果验收或真实 Meta 投放；手机宽度检查不代表 iOS、Safari 或所有设备均已验收。
