# 可视化素材编辑与版本历史

2026-10-21。承接原图编辑和供应商图片工具，覆盖可视化裁剪、画笔擦除、版本比较及从历史版本继续编辑。

## 操作与真值

- 裁剪：在原图上拖出矩形，拖动中心手柄移动、四角调整大小；原有百分比输入保留，支持精确值与键盘操作。坐标以 EXIF 方向校正后的原图为准，与预览的 CSS 大小无关。继续执行先裁剪、再顺时针旋转的持久化任务。
- 擦除：保留矩形选区，新增画笔选区；鼠标、触笔和触屏使用同一 Pointer Events 路径。一个点击也是笔画，撤销/重做作用于已完成的笔画，新笔画清除重做栈，取消手势不提交笔画。准备草稿不调用供应商，之后仍需成本预览与确认生成。
- 对比：在本小轮授权版本中选择来源与结果，滑杆控制左右显示范围，透明处显示棋盘格，支持 100%–400% 视图缩放及滚动。两个原始文件均通过既有授权下载意图和 Blob 客户端读取，不公开存储地址。图片按比例适配结果画框，裁剪/旋转后的不同构图不做虚假的像素配准。
- 历史：按持久化父子关系排列，显示精确版本 ID、来源、创建时间、编辑操作与该版本的审核/使用资格。从旧版本继续编辑会定位其编辑入口，新结果仍分叉为子版本。已冻结或已关闭的小轮只允许查看和对比；历史父版本不在本轮时仅显示来源 ID，不越权补查。

## 画笔合同

`ImageToolSpec` 在原有 `region` 之外增加可选 `strokes`。擦除必须二选一，其他操作不得附带选区。每条笔画包括归一化的 `x/y` 点及以原图短边为基准的笔刷直径 `width`。

- 每次最多 128 条笔画，每条 1–512 点，合计最多 8192 点；点必须有限且在 `[0,1]` 内，直径在 `[0.002,0.5]` 内。界面在安全上限前停止接收更多笔画，允许撤销或提交当前选区。
- 服务端在既有图片尺寸、像素和文件限制下确定性光栅化，最细笔刷至少选中一像素。矩形的原有光栅化规则保持兼容。
- 同一蒙版用于供应商原生 PNG Alpha mask 和服务端结果合成。未选区域的 RGBA 精确保留，原始 Alpha 保留。界面红色标记是选区预览，最终像素范围以服务端光栅化结果为准。
- 笔画完整冻结到原有反馈/生成配方、预览 hash、成本与执行记录中；修改点或笔刷直径产生不同意图。继续使用原有输入校验、供应商能力门禁、成本预留、持久化 Worker 和一次派发语义。

不增加供应商、ComfyUI、GPU 服务或数据库迁移。`include_version_history=true` 的小轮素材投影增加可选 `asset_id`、`created_at` 和 `edit_operation`，普通旧投影及仅 `include_image_edits=true` 的已发布 Web 投影不含这些字段；OpenAPI 和生成客户端同步更新。

## 审核与证据

质量审核始终指向具体 AssetVersion。画笔、矩形、放大、去背景和裁剪/旋转结果都不会继承源版本的人工批准。AI QC 只能提供建议，仍需新版本人工审核；原图、旧审核、冻结交接与历史效果证据不改写。

## 验证

`tests/test_image_brush_editing.py` 检查坐标/数量限制、点/线/图边界蒙版、供应商 mask 极性、选区外 RGBA 精确相等，以及 HTTP → 零费用 Mock 预览 → Worker → 两个同源子版本 → Mock AI QC（不自动批准）→ 各版本人工审核。已有供应商和裁剪回归一并保留；真实 PostgreSQL API/Worker 角色测试增加画笔路径。

前端组件测试覆盖缩放坐标换算、选区移动/调整/取消、笔画撤销/重做、草稿内容、历史来源选择、审核状态、冻结只读与私有 Blob 生命周期。原生浏览器验收：

```sh
cd web
npm run test:image-editor -- /private/tmp/marketai-visual-editor-evidence
```

该脚本编译实际 React 模块，在仅绑定本机回环的测试页使用本地图片/传输 fixture，验证桌面鼠标与移动触屏、裁剪旋转和画笔请求内容、历史源版本选择及对比视图，保存截图和 JSON。它不代替发布后正常登录/MFA 的在线验收，不调用真实供应商或生产接口。

滚动发布保护：版本历史字段单独 opt-in；非画笔工具不输出新增的空 `strokes` 字段，以兼容已发布 Web 的严格校验。Web 的小轮历史读取同时转发两个开关。已有画笔任务或配方落库后，故障优先前向修复；回退至不认识笔画配方的 Worker 前必须处理这些任务，不能盲目重放。
