## Safari 本轮完成范围

使用实际 **macOS Safari 18.6** 的新隔离标签页，登录沿用本机测试账户；所有故障只发生在本机隔离 API，没有提交正式报表或调用模型。

1. 打开已结束 Mock 小轮，选中原受控 CSV 并确认口径；停止本机 API 后，后台刷新显示错误，CSV 和勾选保留，导出/预检/评估按钮暂停。
2. 恢复 API，点击 Refresh 后按钮恢复；用保留的同一文件预检，继续显示无效金额及重复日期问题，不出现确认导入入口。
3. 从页面申请原私有 ZIP 并实际下载。Safari 自动解压后，在 Finder 定位产物；**7 个文件逐一与冻结 ZIP 字节一致**，包括 5 条素材记录、配套文案、媒体与空回传模板。这里核对的是解压后的内容，没有把它写成 Safari 下载原始压缩字节的哈希证明。
4. Safari 重载页面后恢复到当前第二轮，再打开历史第一轮，原 491 模拟花费、错误预检、导出入口和已结束状态均恢复。

隔离记录前后核对：仍为一个有效批次、35 行及模拟花费 491，原评估、收尾、导出引用、策划/生成/QC/修订数量保持不变。原生临时标签页及本轮本机服务已清理。

上轮因控制中断未完成的这组桌面 Safari 恢复/下载/重载步骤现已补验通过。这不代表 iOS/触屏、所有 Safari 版本、全部设备/浏览器或全部基础设施故障均已验收。
