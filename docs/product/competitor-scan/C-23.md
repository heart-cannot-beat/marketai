# C-23 维度标签、购买主张聚类（扫描级修订）、重新聚类、纯函数快照冻结

GitHub #272。Part of Epic #265。Blocked by: C-22 #271。大小 L。含迁移与 OpenAPI。

## 范围
1. 表：`competitor_ad_assessments`（kind=`tags`）、`competitor_scan_assessments`（kind=`clusters`，扫描级追加修订）、`competitor_scan_snapshots`（含 `cluster_revision`）（规格 §11，快照按 (scan_id, hash) 唯一）；`competitor_scans.snapshot_id`；`products.competitor_snapshot_in_drafts`（布尔，默认 true）及其写接口（Member 可改）。
2. Worker **tag** 步骤：只对 `relevant` 观察，按在投天数取前 `max_tagged_ads` 条；词表按产品当前维度词表冻结（复用 `app.external_creatives.vocabulary`）；受治理 `llm_chat`（视觉），DCO 逐卡片看图合成一条建议；输出语言用扫描参数 `language`；调用名是 C-21 预留的 `tag:i`（规格 §5.2）：首次调用前把“序号 → 观察”对应表（在投天数倒序、再按 `ad_archive_id`）冻结进 `evidence_json.tag.assignments`，按 `(Job, "tag:<i>")` 重放；对应表之外的序号在本步结束时释放；费用消费 C-21 的预留。
3. Worker **cluster** 步骤：一次文本 `llm_chat` 把相关观察聚成 `claim_clusters[]`（每簇 ID、一句话主张、广告主列表标 `role=self`、观察 ID、最长在投天数），结果作为 `competitor_scan_assessments` 的新修订追加；输出语言用 `language`；按 `(Job, "cluster:1")` 重放；费用消费 C-21 的预留。
4. Worker **freeze** 步骤：**纯函数、免费、不调用 LLM**。输入 = 观察 + 每条最新 relevance / tags 修订 + 最新 clusters 修订；输出快照 = 扫描 ID、参数、相关观察 ID 列表、判断修订 ID、`cluster_revision` 与按当前相关性过滤后的簇成员、“未归类”列表（相关但不在任何簇里的观察）、按维度值计数、长跑广告（≥60 天）、相邻观察摘要、自家观察摘要；hash 覆盖全部。同一组修订两次冻结得到相同 hash；hash 未变时返回已有快照，不新建行。
5. API：确认 / 修改标签（新修订）；“重新冻结”（免费，Member 可操作，生成新快照）；“重新聚类”报价 + 执行（付费，`quote_llm_chat` 报价、预留、受理、重放；生成新的 clusters 修订，之后自动冻结一次）；汇总（簇、未归类、相邻、长跑、自家对照、AI 一句话结论标“AI 推测”）。
6. 翻转语义（与 C-22 衔接）：翻为无关的观察在下次冻结时从簇成员中移除；翻为相关的进入“未归类”，直到重新聚类。

## 验收
- 规格场景 7（后半）、8、14、15。
- 标签确认与外部素材的确认修订语义一致（追加、最新生效、未确认不进快照计数的“已确认”列）。
- 确定性：同一组修订连续两次“重新冻结”得到相同 hash、不新建快照行、不产生 LLM 调用记录；翻转一条后重新冻结，hash 改变、该观察出现在“未归类”或从簇中消失；重新聚类产生新修订与新 hash，并有报价、预留与结算记录。
- Mock 的聚类夹具覆盖：Northpeak“安全焦虑”簇、Acme Charge“一套转接头覆盖所有充电桩”簇、含 `role=self` 的簇。
- 开关：改为 false 后读取为 false；跨 Workspace 改开关 404。
- 调用名：Worker 重投后 tag 与 cluster 命中同一序号的重放，不新增调用记录；只有 12 条相关观察时，`tag:13..max_tagged_ads` 的预留在本步结束时全部释放；重新聚类在它自己的 Job 下用 `cluster:1`。
- 负向：跨 Workspace 读快照 / 汇总 / 确认标签 / 重新聚类返回 404；Member 可确认标签、重新冻结与重新聚类（受 Spend Guardrail）。
