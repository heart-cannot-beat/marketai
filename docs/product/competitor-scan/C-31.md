# C-31 竞品面板壳：清单、解析与确认卡片、扫描报价与进度

GitHub #274。Part of Epic #265。Blocked by: C-13 #269 与 C-21 #270 的 **OpenAPI 先行 PR**（两者合并后总控可加 `ready-for-agent`，评论注明依据的 PR；实现 PR 未合并时用 Mock 服务开发）。大小 L。前端。

## 范围
1. 产品理解页新增“竞品”区（规格 §9）：本 Issue 负责容器、路由、`competitors` locale 命名空间（en + zh-CN，不进 `common.json`；若 C-24 已先创建则追加键）与 `web/components/competitors/` 目录；C-32、C-33 只在该目录加组件，不再改 `MarketingWorkspace.tsx`。
2. 清单：输入框接受四种输入；每行显示确认状态、`role`（竞品 / 自家）、最近扫描时间；归档（Owner）。
3. 解析与确认卡片：解析前显示费用（额度与 USD）；候选卡片含头像、主页名、别名、分类、赞数、IG 账号、在投广告数、落地页域名、域名命中标记；多候选可切换。
4. 扫描：参数（市场默认方案市场、每家页数、关键词、视觉打标上限）、最高费用两行（供应商额度与 USD、LLM 上限）、确认；进度按步骤；`partial` 显示续跑按钮与剩余报价；`uncertain` 显示待对账页、自动对账结果与 Owner 手动标记入口；失败显示步骤与原因（错误码文案 en/zh-CN）。
5. 缺 `market_data` 凭据或缺 AI 凭据任一项：只提供受控 Mock 选项（整次扫描都是 Mock），页面、记录标明模拟；引导 Owner 去设置页配置缺的那一项。
6. 手机 390×844 可用。

- 新增 key 同时写 en 与 zh-CN，切换语言后无另一种语言残留。
