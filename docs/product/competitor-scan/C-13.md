# C-13 竞品清单、解析任务与主页确认

GitHub #269。Part of Epic #265。Blocked by: C-11 #267、C-12 #268。大小 L。含迁移与 OpenAPI。

## 范围
1. 表：`competitors`（含 `role=competitor|self`）、`competitor_identity_confirmations`（规格 §11），复合外键 + RLS；确认表追加只读触发器。
2. 输入解析（规格 §4.1）：Facebook 主页链接、Ad Library 链接（`view_all_page_id`）、官网域名、名字；前两种不搜索直接得到 page id / 别名，不发起解析任务。
3. **解析任务 `competitor.resolve`（规格 §4.4）**：独立付费 Job；报价 = `page_search` × 1 + `probe` × min(3, 候选数)；确认前显示最高额度与 USD；原子预留 + Spend Guardrail；每次调用一个 ProviderCallAttempt + dispatch fence，按 `credits_charged` 结算；候选、打分（§4.2）、域名探测写入解析证据；结果 72 小时内可重复用于确认（短于头像签名链接的有效期，卡片不存头像，过期后显示占位）。
4. API（`/api/v1/competitors`）：创建竞品（`Idempotency-Key` 重放）、解析报价、发起解析（返回 Operation）、读取解析结果（候选 + 打分 + 域名命中）、确认（写入修订，引用 `resolve_job_id`）、列表、归档（Owner）。自动确认只在“给了链接”或“名字完全一致且域名命中”。
5. **OpenAPI 先行 PR**：先合 `contracts/openapi/marketai-domain-v1.json` 与 allowlist（供 C-31 提前开工），再合实现。

## 验收
- 规格场景 1、2、12、14。
- 负向：跨 Workspace 读竞品 / 解析结果 404；Member 可创建、解析与确认，归档需 Owner；同一确认重复提交返回同一修订；解析任务 402 时释放未用预留。
- 用 Mock 夹具复现 P0 的“Acme Charge 8 个同名主页”与“Brightvolt 排在捷克活动主页之后”，打分 + 域名探测后正确候选排第一。

## 产出
- 迁移、OpenAPI 先行 PR、路由、服务、Worker 分支、测试；PR 记录解析的真实费用（若用真实 Key）。
