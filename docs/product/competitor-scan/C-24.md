# C-24 planner 消费竞品快照 + 三类检查 + 方案审查展示

GitHub #273。Part of Epic #265。Blocked by: C-23 #272。大小 M。**无迁移，但改 OpenAPI**（`ReviewItem.kind`、`competitor_overlap`、`competitor_snapshot_stale`），在串行链上位于 C-23 之后、C-33 之前；改 `app/marketing/contracts.py`、`planner.py`、`plan_review`、`MarketingPlanReview.tsx`。

## 范围
1. `TestPlan` 新增可选字段 `competitor_snapshot_id`（ADR 0013 做法，写进 `marketing_revisions.content_json`；不加列）。起草时服务端默认取同产品、同市场的最新快照写入；“同市场”按 `MARKETAI_MARKET_COUNTRY_ALIASES_JSON` 把方案 `market` 规范化为国家码后与扫描 `country` 比较，无法规范化则不选并在投影暴露 `competitor_market_unmatched`；`products.competitor_snapshot_in_drafts`（C-23 落地）为 false 时不写入。
2. `inputs["competitor_snapshot"]`（规格 §7.2）：`claim_clusters`（广告主数、最长在投、库链接）、“未归类”摘要、长跑广告摘要、相邻观察摘要；不传素材与完整文案；每簇 ≤200 字；计入现有 96000 字节上限。快照语言与方案 `strategy_language` 不同时，由 planner 在输出里转述。
3. planner 输出：每个角度 `competitor_overlap: [cluster_id…]`；引用竞品的角度在 `rationale` 注明“竞品观察”。系统提示词新增约束：只用于说明角度“竞品已讲 / 未讲”；不得写成本产品事实或证据；不得复用竞品标题、正文、画面描述。
4. `ReviewItem.kind` 新增三类，服务端按快照确定性计算：
   - `competitor_crowded`（advisory, system）：角度引用的簇合并后非自家广告主数 ≥3；服务端校验簇 ID 存在于快照，数字只从快照取。
   - `competitor_gap`（advisory, system）：角度未引用任何簇；文案固定附注“可能是空白，也可能别人试过无效”。
   - `competitor_copy_reuse`（**blocking**, system），两条规则任一命中：（a）headline 归一化后与任一相关观察的标题或卡片标题整句相同且 ≥3 个词 / ≥6 个 CJK 字符；（b）headline 或 body_copy 与相关观察的标题、正文有 ≥8 个连续相同词（拉丁）或 ≥12 个连续相同字符（CJK）。`role=self` 观察的文案不进比对语料；产品名、品牌名、认证名、CTA 常用词不计入。
5. 读取投影暴露 `competitor_snapshot_stale`：同产品同市场存在创建更晚且 hash 不同的快照时为真；其他市场不算；同时暴露 `competitor_market_unmatched`。
6. 前端：`MarketingPlanReview.tsx` 展示三类 kind（含来源观察链接），文案进 `competitors` locale 命名空间（en / zh-CN；若 C-31 尚未合并则由本 Issue 创建该命名空间文件，只放自己的键），组件同时加载 `common` 与 `competitors`；不改 `MarketingWorkspace.tsx`，也不改 `common.json`。

## 验收
- 规格场景 9、15。
- 无快照或开关关闭时 planner 行为与现在完全一致（回归：现有 planner 测试全部通过）。
- 两类 advisory 不阻塞确认；`competitor_copy_reuse` 阻塞确认且 UI 指出来源观察；`plan_review` 去重规则不把它们与 `angle_overlap` / `evidence_gap` 混淆。
- 规则 (a)：照抄一条 3 个词的竞品标题被拦；规则 (b)：抄 8 个连续词被拦；误报检查：用 P0 夹具里的 Acme Charge 文案与一份不抄袭的英文方案跑一遍，不触发。
- `market="北美"` 的方案映射到 US 快照；`market="火星"` 不选快照且投影 `competitor_market_unmatched=true`；与自家在投标题整句相同不阻塞。
- OpenAPI 重生成后前端客户端编译通过。
