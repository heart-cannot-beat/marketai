# C-11 `market_data` 凭据作用域 + ScrapeCreators 自助入口 + 价格表

GitHub #267。Part of Epic #265。Blocked by: C-01 #266。大小 M。

## 范围
1. 凭据：`binding_scope=market_data`、provider `scrapecreators`，复用现有 CredentialVersion、加密、Owner/MFA 与隔离规则；设置页新增独立自助入口（添加 / 启用 / 替换 / 移除），与 OpenAI、Gemini、Seedream 并列。
2. 验证：用 `GET /v1/account/credit-balance`（请求头 `x-api-key`，免费）；**该接口对无效 Key 也返回 200**，以 `creditCount > 0` 判定有效，0 视为无效或无余额并给出对应文案。
3. 价格表：`MARKETAI_MARKET_DATA_MAX_COSTS_JSON`，键为供应商 → 操作，操作五种：`page_search`、`probe`、`page`、`keyword_page`、`ad_refresh`，值 `{"credits": 1, "credit_usd": "0.00188"}`；改价同步 `MARKETAI_PRICE_REGISTRY_VERSION`；未配置时不能提交真实解析或扫描（但可用 Mock）。
4. 首次配置时的说明文案：调用使用用户自己的供应商账号，供应商条款的使用关系在用户与供应商之间（规格 §10）。

## 验收
- 负向测试：Member 不能管理凭据；跨 Workspace 读取凭据返回 404；无效 Key 显示“无效或无余额”，不显示“已连接”。
- 价格缺失或缺少任一操作时，报价接口返回明确错误码（新增错误码带 en/zh-CN 文案）。
- `make verify` 通过。
