# C-12 `AdLibrarySource` 协议 + ScrapeCreators 适配器 + 受控 Mock + 规范化

GitHub #268。Part of Epic #265。Blocked by: C-01 #266。大小 M。纯领域代码，不含 API、不含迁移。

## 范围
1. `app/competitors/sources/base.py`：`AdLibrarySource` 协议，方法 `search_pages(query)`、`ads_for_page(page_id, country, status, cursor)`、`search_ads(query, country, status, cursor)`、`ad_detail(ad_archive_id)`；每个实现声明平台、支持国家、计费单位与每次调用对应的价格表操作（`page_search` / `probe` 或 `page` / `keyword_page` / `ad_refresh`）。
2. `sources/scrapecreators.py`：对应 `/v1/facebook/adLibrary/search/companies`、`/company/ads`、`/search/ads`、`/ad`；请求头 `x-api-key`；返回原始 JSON + `credits_charged`、`credits_remaining`、`cached`、耗时；429/5xx 由调用方决定重试，适配器不重试、不换供应商。
3. `sources/mock.py`：受控 Mock，夹具来自 P0 原始响应（`data/p0-scrapecreators/runs/20261026-163158/raw/`）。**脱敏规则：品牌主页名、广告标题 / 正文、落地页域名统一换成虚构品牌（#428 映射；下游验收按 Acme Charge、Brightvolt、Halcyon Motors、Northpeak、Kestrel Power、Lumenline 断言），域名一律 `*.example`；个人账号广告主改为化名；签名素材链接替换为夹具内占位图；去掉头像 URL 与追踪参数。** 覆盖：DCO 2–3 卡片、VIDEO、无正文、`collation_count > 1`、空结果、402、分页 cursor、`search_pages` 的 Acme Charge 8 个同名候选与 Brightvolt 排在捷克活动主页之后的候选列表。
4. `normalize.py`：供应商响应 → `CompetitorAd`（规格 §5.3，含 `origins`），每个字段记录来源字段名；`landing_domain`、`days_running` 派生；缺失不猜。
5. 素材链接过期时间解析：`oe=` 十六进制 unix 时间。

## 验收
- 规范化单元测试覆盖 P0 全部 5 种 `display_format`；DCO 顶层视为第 0 张卡片。
- Mock 与真实适配器通过同一套契约测试（同一输入形状、同一输出形状）。
- 夹具中不含任何 `fbcdn` 签名链接、头像 URL 或 ScrapeCreators Key；无网络调用进入测试。

## 产出
- `app/competitors/sources/`、`app/competitors/normalize.py`、测试与夹具。
