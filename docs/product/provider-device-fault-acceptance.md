## 结论与未完成项

- **Gemini、Seedream 的真实附图验收暂停**：正式工作区没有这两家的生成凭据，也没有对应的最大成本报价。当前 Owner 原生设置页仅提供 OpenAI 录入，两家的自助凭据入口也待补；底层受保护凭据接口已支持逐供应商绑定，不将接口存在算作自助流程验收。用户明确表示目前没有 Key；不代找密钥、不使用其他工作区/平台密钥、不增加费用。接入能力与受控 HTTP 检查不等于真实供应商验收。
- **免费软件验收通过**：修正 Seedream 4.5 的默认尺寸路径、图片供应商故障的费用判定，以及服务中断时的用户提示；证据分层如下。
- **真实 Meta 业务效果等待报表**：没有新广告，没有假回传，没有新增真实业务资格。正式工作区里真实客户产品的最终 A/B 和私有导出保留。
- **浏览器尺寸验证不等于实机兼容验收**：此次没有实际 iOS/Safari、Android、触屏或多个浏览器内核，不将它们标为通过。

将来取得 Key 后仍需核实当时可用的具体模型、输入/输出限制与最大报价，获得新增费用授权，然后另建真实附图样本，检查发送凭据、参考图身份、实际输出、视觉 QC、反馈修订及人工确认。没有凭据时不能签收这些项目。

## 修正与受控故障证据

真实的 HTTP 请求适配器连接测试传输层；网络端不连接 Google、火山方舟或 OpenAI。请求包含实际 JPEG 数据，不以文件名或 URL 代替。这里证明软件协议行为，不能证明供应商接受该请求或画面保真。

Seedream 4.5 最低总像素 3,686,400 的约束已对照 [火山方舟图片生成 API 文档](https://docs.volcengine.com/docs/ark/image-generation-api?lang=en) 核实；四种修正尺寸均满足这一约束。文档核对不能代替真实请求验收。

| 项目 | 本次行为与证据 |
| --- | --- |
| Seedream 4.5 默认尺寸 | 营销入口原来绕过共享尺寸规则，1K 默认档会发送低于 4.5 要求的旧尺寸。现复用 `seedream_size`，四种前台画幅均发送已有 2K 对照尺寸；原图附带 JPEG 数据。保留 4.0 的原尺寸语义。供应商实际接受情况待 Key 验证。 |
| 明确拒绝 | 三家图片适配器的 HTTP 400/401/403/422 根据状态码处理；不按正文词语猜测是否已执行。真实命令/预留/适配器/Worker 集成验证 400 后释放预留，同任务再次执行不重新请求。 |
| 不确定响应 | 429、500、502、503，即使正文包含 `invalid`、`policy` 或 `400`，仍保守保留不确定性；超时、无效 JSON、无图和 HTTP 200 安全拒绝也不假定免费。三家适配器的 503 集成验证保留原预留、进入 uncertain，恢复执行不再次请求。 |
| 损坏/缺失参考 | 无效字节、缺失文件在 HTTP 客户端建立前拒绝；不静默丢掉参考图后转成纯文本付费生成。 |
| 生成与 QC 恢复 | 调用边界之前失败释放费用；边界后崩溃、视觉 QC 超时和结果解读超时保留不确定费用并禁止盲目重发。对应既有契约在本次重新通过。 |
| 版本与导出 | QC 不自动批准、修订后重新审核、部分组合未完成不可导出、失败导出重试原冻结选择、过期评估不可付费解释；CSV 去重/更正和跨租户拒绝继续通过。 |

新增适配器故障文件共 46 项；费用集成新增一项、含三家 × 两类响应的 6 个子场景。修正前专项有 16 个失败，修正后通过。最终合并定向后端 **225 项、9 个子场景**通过，前端营销相关 **7 组、38 项**通过；类型、定向 lint、生产构建及差异空白检查通过。专项互有重叠，不累加，也不称为全仓回归。规格 12 场景的 36 项映射在此次后端回执中重新匹配通过。

## 原生界面与真实本地进程

仍使用真实登录、BFF、API、PostgreSQL、Worker 与私有存储，隔离工作区中的外部图片为明确 Mock。

1. 360/390px 中编辑测试问题，主动停止本轮本地 API 后保存。页面保留输入，提示服务无法连接，并提供“重试同一动作”；恢复 API、重试及刷新后找回准确内容。随后用页面还原原问题。新组件测试同时核对请求身份与正文一致。
2. Worker 未运行时，从页面确认一张 USD 0 的 Mock 图片。只读数据库确认一个原任务 `job_c564c61bd0f94d2baff3781d79eaec69` 为 queued、attempt 0；界面/API 重启后仍是同一记录。
3. 启动 Worker 后成功输出一个版本 `av_5dad8e3ebf1e4d1ead49dce4ffa46366`，attempt 1。再次重启 Worker，任务、版本和文件哈希均不变；没有重复生成。新版本仍待审核，不导出。

这些是排队恢复、已完成任务防重与 API 断连实测。付费派发边界后的进程中断使用自动化控制，不在真实供应商或生产系统注入故障；不把一次 Mock 恢复称为所有生产故障均已穷尽。

## 屏幕与键盘

浏览器视口为 **320×740、360×800、390×844、768×1024、1024×768、1440×900、844×390**。检查测试方案/共享表达、生成设置/恢复任务、QC 私有预览、历史结果和正式导出共五类状态。页面边界与关键输入/按钮检测无横向溢出，另保存代表状态截图；窄屏结果表在自身容器滚动。键盘 Tab 可到达表格滚动容器，方向键改变横向位置；Enter 可展开表达对照。私有预览实际加载成功。

这不是实机、触屏、Safari 或辅助技术的全面测试；浏览器缩放、弱网长时间运行、更多设备/内核及真实供应商限流仍可继续扩展。没有因这一轮软件验收签收真实模型质量或商业效果。
