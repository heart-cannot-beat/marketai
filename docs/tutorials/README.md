## 下载与阅读

GitHub 默认展示 HTML 源码。在文件页使用 **Download raw file / 下载原始文件**，把两份 HTML 保存到同一文件夹，再用浏览器打开。每份文件的图片、样式和查看器都内嵌，没有远程字体或图片依赖，可以离线阅读；同目录保存即可互相跳转。

桌面有侧边目录；手机展开目录后点章节会自动收起。点击截图放大，按 Escape 或“关闭”返回。
