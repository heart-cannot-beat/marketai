## 范围

- Owner 可通过持久化 Operation 结束结果不确定的策划、解释或视觉质检调用；保留原始不确定记录，按原预留上限保守记账，不重发供应商请求。
- Worker 将生图、营销质检、策划和通用任务分开执行，默认并发 2 / 1 / 1 / 1；保留原有任务处理、数据库错误退避和安全关闭。
- 工作流按项目筛选并批量读取素材与审核、文件回执，空闲时停止轮询，生图提交或恢复后主动刷新。
- 工作流及证据交接采用嵌套响应模型，前端类型、白名单和校验器统一生成。
- 媒体币种和归因窗口可配置，导出、报表预检、评估和解释沿用冻结口径，不做隐式换算；同一大轮不允许换币，供应商费用独立以 USD 核算。
- 历史测试支持按名称、资料或 ID 搜索及稳定游标分页，默认每页 50 条、最多 100 条；页面支持继续加载。

已保留生产的实物参考图校验、私有文件适配、人工反馈修订、过期证据门禁、无数据解释、后续小轮预算限制以及本地化/放量证据交接。

## 迁移与兼容

生产迁移链为 zs4f5a6b7c8d → zt5a6b7c8d9e → zu6b7c8d9e0f。新增两个读取索引、一个任务领取索引和受限费用汇总函数；原任务领取身份、租户签名、审计及租约语义保持。

数据库统一通过正式 Release 服务：私有存储检查、两库备份、Prisma、角色收敛、目标 nonce 验证、Alembic、权限复核和无漂移检查。权限重置和重授在同一事务内完成。保留 API 已有的租户费用报表读取权限；不新增 API 对费用预留或质检结果的 UPDATE 权限。

旧的无参数能力、列表、项目和策划请求保留原字段。新客户端显式使用分页参数、include_reporting=true 和 include_recovery=true、include_polling=true；默认美元/7-day click + 1-day view 的证据标识保持，旧结果口径在读取时补齐，不改写不可变评估。
