# ADR 0018: 广告内容先于测试设置

**Status:** Proposed (Accepted on merge)  
**Date:** 2026-11-16  
**Decided in:** #187（维护者决定，2026-11-16）  
**Supersedes:** [ADR 0010](0010-organize-marketing-tests-around-questions-and-scoped-evidence.md) 第三段的默认入口（开关打开之后）  
**Amends:** [营销测试规格](../product/ai-marketing-testing-spec.md) §5.1、§6、§8、§8.2；[前台两项配置合同](../product/front-flow-two-config-contract.md) §3.1、§6  
**Relates to:** [ADR 0005](0005-separate-commercial-access-usage-and-provider-cost.md)（访问、用量与 Provider 成本）、[ADR 0011](0011-front-flow-layering-and-step-up-scope.md)（前台分层）、[ADR 0013](0013-ad-language-brand-baseline-and-style-variation-are-plan-fields.md)（广告语言、品牌底线与风格）、[ADR 0014](0014-competitor-observations-inform-hypotheses-not-evidence.md)（竞品观察）

## 背景

现在用户看到第一张图之前要过四关：确认产品卡、逐条确认产品事实、确认整份测试方案、确认生成费用。测试方案里有预算、目标成本、落地页、停止规则等二十多项。

原因在数据结构。测试方案（`TestPlan`）一份文件同时装着广告内容（主张、讲法、文案、画面说明）和测试设置（预算、目标、周期、判断规则），而出图要求整份方案已确认（`generation_drafts` 要求 `plan_confirmed`），起草方案又要求全部事实已确认（`facts_unconfirmed`）。只改界面改不掉这个顺序。

维护者 2026-11-16 的判断是产品“从一开始就很复杂”，并定了四件事：把方案拆成广告内容和测试设置两段；仍然由客户自己的 Key 付 AI 费用；去掉没有 Key 时的受控 Mock 体验；竞品从出广告的流程里拆出来。完整设计见[设计文档](../superpowers/specs/2026-11-16-ads-first-opening-design.md)。

## 决定

1. **新产品先有广告，再定测试。** 读完产品就起草购买主张并出图，不要求用户先确认产品理解，也不要求先确认测试方案。这条路径在数据里记为 `flow = "ads_first"`。
2. **没核对的内容可以出草稿，但草稿有边界。** 没核对的产品事实和没核对的产品照片可以用来出广告草稿。草稿不能导出，不能进入任何小轮，不构成效果证据。出图配方如实记录出图时哪些事实还没核对；这是证据记录，不等于把 AI 的提议发布成已确认的版本。
3. **导出的三个条件。** 一张广告同时满足下面三条才能导出：它引用的事实都已由用户核对，并且和出图时一致；它用到的产品照片已由用户核对为真实产品照片且有权使用；检查没有未处理的问题，并且检查对照的是当前已核对的事实。引用的事实被改或被删，或者照片被否定，这张广告需要重出。
4. **测试设置在要测试时才确认。** 预算、目标、周期、投放条件和判断规则，等用户决定测试时再问。冻结小轮时的快照仍是完整的 `TestPlan`，判断协议、评估算法和证据规则不变。
5. **Key 和示例。** AI 费用仍由客户自己的 Key 支付，ADR 0005 不变。首批的几次调用合成一个最高费用，确认一次；每次调用仍单独预留、单独结算。没有 Key 时不出图。主流程不再提供受控 Mock 体验，包括模拟检查、模拟解读和模拟投放数据；Mock 保留为测试和演示手段。
6. **导航按产品组织，竞品独立。** 默认入口从营销测试页改为按产品组织的导航。竞品成为独立页面，数据仍按产品存；它和广告想法之间只保留提示和“拿去做主张”两处连接。高级工作台仍折叠在导航里，ADR 0011 的这一条不变。

不变的：

- 事实的出处校验照旧自动执行：引文必须能在原始资料里找到；认证、参数、价格类的说法必须有原文依据。没有出处的说法不进入主张和文案。
- 只有用户核对过的内容成为已确认内容。没核对过的规格、卖点、受众、外观要求保持为 AI 的提议。
- 改版前建的测试（`flow = "plan_first"`）沿用原来的状态、接口和页面，不迁移。
- 不可变版本与只追加证据、付费调用的持久任务、幂等和预留、租户隔离、Meta 写入关闭，这些不变量全部适用于新路径。
- ADR 0009 对客户工作区真实读取 Meta 的限制不变；报表回传仍是用户上传。

我们没有选的：

- **只换界面。** 出图前仍要确认整份方案，根因还在。
- **在现有流程旁边另加一个快速入口。** 用户看完图会掉回现在的页面，而且又多一代并存的流程。
- **平台垫付首批草稿。** 要改 ADR 0005 的约定，并且由平台出钱。
