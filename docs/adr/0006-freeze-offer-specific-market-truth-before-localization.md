# Freeze offer-specific market truth before localization

Every LocalizationBatch will bind one ProductVersion and the Winner's exact OfferVersion, resolve one immutable TruthPackage with per-market provenance and readiness, and create child AssetVersions only from approved LocalizedCopyVersions and bounded edit/QC Attempts; localized outputs inherit provenance but never human approval or Winner status. We accept per-market partial outcomes, explicit removal of unsupported claims, and downstream `stale_truth` invalidation because preserving a source-market price, inferring a local amount, or mutating an old output would create unverifiable commercial claims; we reject live per-item price reads, currency conversion, first-variant pricing, proportional component estimates, hard-coded shared EUR contexts, model-generated numbers, file-name identity, and automatic Winner inheritance for the same reason.
