# 围绕问题与有边界的证据组织营销测试

依据 2026-10-16 确认的产品方向，MarketAI 以业务目标下的大轮、回答具体问题的小轮及可包含多条素材的测试组组织测试；广告角度、动态表达、元素配置、创意组合和素材保留明确关系，业务达标、相对表现与认识范围分别记录。我们接受新组织模型和旧实验兼容映射的成本，因为自由维度的排列组合与单素材 verdict 无法可靠回答营销问题，固定矩阵会排除独有表达，单次胜出也不能证明组合可复用。

[产品规格](../product/ai-marketing-testing-spec.md) 与 [实施计划](../product/ai-marketing-testing-implementation-plan.md) 覆盖 v9 中强制六区主流程、默认全组合、按标签跳过失败组合及一候选一素材/一 AdSet/一 Ad 的通用组织假设。ADR 0004 的同源 BFF/领域所有权和版本化接口边界继续有效，其六区 UI 对齐要求让位于新的测试主流程；ADR 0009 的 PAUSED Launch 保留在原有隔离验证范围，不定义新测试组结构。当前客户在 Meta 完成投放，MarketAI 负责交接与回传；ADR 0008 的放量只建议边界继续有效。

本次改版进一步替换 ADR 0011 的默认产品/测试分步入口：登录、工作区首页、工作区切换回退、邀请接受及 MFA 设置完成后进入 `/w/{slug}/experiments`。ADR 0011 的认证与登录 MFA 继续生效；其按条目类型约束 step-up 的规则已被 [ADR 0015](0015-mfa-only-at-login.md) 取代，MFA 只在登录时验证；已有生成、创意库和历史实验作为支持能力保留。
