# 广告语言、品牌底线与风格变化属于版本化测试方案

依据 2026-10-23 的看板与出图质量方向，我们决定把广告输出语言（`ad_language`）、准确的版本化品牌底线（`brand_kit`）引用、风格是否为测试变化（`style_variation: held | tested`，默认 `held`）纳入版本化测试方案，并随生成配方冻结，作为 QC 与结果解释的输入。若只把它们写成可变 Prompt 片段，旧图无法复核采用了哪套约束，随机风格差异也会被错误解释成角度效果；我们接受字段校验、版本兼容及重新预览的成本，以保留可追溯的比较含义。

界面语言、内部策略语言（`strategy_language`）和广告输出语言分离：策略语言默认跟随界面，广告语言由投放市场与用户选择后确认，生图结构化 brief 使用英文。此决定替代「策划统一简体中文」并连带决定广告文字的默认做法；旧方案缺少语言时只提出待确认候选，不静默改写文案、配方或历史 QC。语言或品牌版本等关键条件变更形成新方案/配方版本，使待执行预览失效，已完成的历史记录保持原意。

品牌底线覆盖 Logo、字体、配色、可读性与禁用内容，Logo 沿用已发布参考素材及其资格门禁；产品当前配置不能反写历史方案。`held` 把视觉风格列为保持条件，`tested` 把风格列为主动变化并说明各组风格；不同表达可有不同风格，但任何差异都必须按方案记录且不能突破品牌底线。特定因素比较不得同时主动测试其他因素，未控制或 QC 发现的偏离进入局限，不据此宣称角度因果效果。

具体合同见[产品规格 §6.1](../product/ai-marketing-testing-spec.md#61-语言与风格)；表达区分、参考冻结和单图/对照检查仍分别服从 §4、§5.1、§9。此 ADR 不改变 ADR 0010 的问题与证据边界，也不把语言/质量通过提升为投放有效结论。
