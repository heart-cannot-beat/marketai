# Adopt a hardened BoxyHQ control-plane fork

MarketAI will use a pinned fork of BoxyHQ SaaS Starter Kit as the open-source starting point for identity, Workspace membership, invitations, subscriptions, administration, and the frontend shell. The fork is accepted only behind the production gates in `docs/research/2026-08-25-open-source-saas-control-plane.md`: separate database ownership, invitation-only entry, Owner/Member server-side RBAC, a short-lived asymmetric BFF-to-FastAPI identity token, reviewed migrations, negative isolation tests, and remediation or disabling of unsafe upstream features. We rejected Open SaaS because its shipped model is user-scoped rather than Workspace-scoped and would introduce Wasp as a second application backend; we rejected the FastAPI-template/Supabase composition because it supplies strong components but leaves most of the SaaS control plane to be built and would duplicate the existing domain service if adopted wholesale.
